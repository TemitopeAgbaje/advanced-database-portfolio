# Advanced Database Systems Portfolio

**Course:** MIT 8103 Advanced Database Systems
**Case study:** Supalogi (simulated ride-hailing platform)

Supalogi connects riders to drivers in Lagos, Abuja and Accra. It handles trip
booking, driver matching, payments and ratings. Every portfolio activity below
uses this same case study.
